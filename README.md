# BusinessBoosts Service Pricing Calculator, V2 Production Candidate

This folder contains the deployment-ready static version of the approved V2 calculator.

## Local testing
Open `index.html` in a browser.

## Vercel deployment
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Import the repository into Vercel.
4. Choose Framework Preset: Other.
5. No build command is required.
6. Deploy.
7. Connect your preferred custom domain, for example `tools.businessboosts.mu`.

## Current product scope
No login, database or saved calculations are included in this version. All calculations happen in the user's browser.
